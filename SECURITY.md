# Security Policy

## Supported Versions

Security updates are provided for the latest release on the primary development branch:

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

We take the security of StanClip seriously. If you identify a potential security issue:

1. **Do not disclose it publicly** through public GitHub issues or discussions.
2. Please report the vulnerability privately via [GitHub Security Advisories](https://github.com/eswarmadapani/StanClips/security/advisories) or contact project maintainers directly.
3. Provide detailed steps to reproduce the issue, including affected endpoints, environment configurations, and proof-of-concept payloads where applicable.

Maintainers will acknowledge receipt, evaluate the impact, and prepare a patch in a timely manner. Thank you for helping keep our users safe.
